Trust boundaries

Who is allowed to decide.

Untrusted: ad copy, the rendered page, Kane logs. They are data, never instructions.

Trusted: the frozen contract, oracle and gate; the local operator. The oracle never reads the store’s shipping function.

Human: the merge. The agent proposes; the human approves.

Public: static, sanitized recorded/ evidence; no .data, no Kane, no writes.

Failure states / proof

The gate fails closed.

BROKEN → gate closed → repair loop. INCONCLUSIVE / INFRA_ERROR → no verdict, no green.

HONORED → gate open → receipt. A timeout is never “verified”.

HONOREDBROKENINCONCLUSIVEINFRA_ERROR

Proof chain: contract SHA → objective hashes → run IDs / exit / evidence SHA → audit → gate → receipt. Hash-linked, not signed.

Scope / not in P0

What this is not.

This is the implemented P0: Node HTTP + files + local CLI. The earlier SQLite / Next.js / hosted queue design is not the runtime.

Not built: real payments, arbitrary URLs, Shopify/Meta connectors, scheduled monitoring, auto-deploy, signed receipts, in-app autonomous repair.

Public: landing, campaign, why-kane, gate, audits, receipt, store, before. /compile and /check/* return 404.
