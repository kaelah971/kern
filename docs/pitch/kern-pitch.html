03 / Why now

A green test is not a promise.

AI agents can change the pricing code, write the test and call the task done. The faster the loop, the more dangerous a self-certified “passed.”

01Too broad

Free everything.

The $35 control breaks. The promise becomes a giveaway.

02Too narrow

Miss the boundary.

The exact $50 cart still pays. The edge case survives.

03Self-certified

Weaken the test.

Green, and meaningless. The agent graded itself.

The agent can change the code. It cannot be the witness.

08 / When something goes wrong

The vendor needs a receipt, not an argument.

The Promise Receipt is the customer-side record for the tested conditions: what was promised, what the checkout showed, which code produced it, and what it does not prove.

01the ad snapshot and the frozen contract hash
02each cart’s promised vs observed value
03Kane run IDs, exit results and evidence hashes
04the code revision, patch and human approval
05the gate status and the exact scope

A reproducible customer-side record. Not a recording of every shopper.

hash-linked, not signed
not a certification

10 / Where Kern sits

Not a price monitor.
The promise firewall.
